# Use hosted OpenAI AI for the evaluation demo

The concept described customer-controlled inference as an eventual product
objective. In Round 2 (D-008), the user selected the OpenAI API for the first
release, including English and Urdu voice/text interaction, and explicitly
deferred actual local inference. The demo therefore depends on external AI
connectivity and must truthfully show hosted inference; model selection and the
text/voice API architecture remain undecided.
