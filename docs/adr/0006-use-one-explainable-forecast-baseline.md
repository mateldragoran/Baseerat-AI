# Use one explainable material-consumption baseline

Accepted on 31 October 2026. To keep the demonstration focused, use
seasonal_naive_v1 over complete
monthly actual usage, with prior-year source months, a documented approximate
band and chronological evaluation. This favors a reproducible transparent
baseline over model selection/scenario machinery. Exact eligibility, cutoff,
window, missingness, reversal and rounding rules are fixed in architecture A-08;
no institutional accuracy claim follows from synthetic evaluation.
