# Compose application tools for AI-led analysis

After clarifying the difference between application tools and generated-program
execution, the user selected approach A for the demo (D-025). The AI can plan
multi-step investigations and combine flexible query, calculation, forecast,
chart, and artifact tools; a general-purpose generated SQL/Python execution
environment is deferred. New analytical methods need a supported tool, making
the capability boundary explicit while preserving unscripted question handling.
