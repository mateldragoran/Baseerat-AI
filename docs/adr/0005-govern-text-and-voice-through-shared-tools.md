# Govern text and voice through the same application tools

Use one application tool/evidence/action contract for Responses and Realtime,
with direct browser/provider audio and a bounded authenticated server sideband.
The browser/provider session configuration is not an authorization boundary;
server call binding, current grants, durable operations and confirmation control
all effects. Accepted in final package approval on 31 October 2026; BAS-002
compatibility evidence remains required. This does not add a separate always-on backend.
